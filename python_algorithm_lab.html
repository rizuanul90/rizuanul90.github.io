// PROJECT OVERVIEW

Project Description

At my organization, access to restricted content is controlled with an allow list of IP addresses stored in allow_list.txt. A separate remove list identifies IP addresses that should no longer have access.

I created an algorithm to automate updating the allow list file — removing any IP address that appears in the remove list, then rewriting the file with the revised set of approved addresses.

// SECURITY CONTEXT This automates a critical access-control operation, reducing human error and ensuring revoked IPs are removed promptly from the allow list.
// STEP 01

Open the File that Contains the Allow List

First, I assigned the file name as a string to the import_file variable, then used a with statement to open it safely.

python 
# Assign the file name to a variable
import_file = "allow_list.txt"

# Open the file using a with statement
with open(import_file, "r") as file:
    # file operations go here
    pass
// WHY with open()? The with statement automatically closes the file after the block exits — even if an error occurs — preventing resource leaks. The "r" argument opens the file in read mode, and as file stores the file object in the variable file.
// STEP 02

Read the File Contents

I used the .read() method inside the with block to convert the file's contents into a single string, storing it in ip_addresses.

python 
with open(import_file, "r") as file:
    # Read file contents into a string
    ip_addresses = file.read()

The .read() method converts the file into a string, making it accessible for further manipulation in Python — such as splitting into a list or searching for specific values.

// STEP 03

Convert the String into a List

To remove individual IP addresses, I needed them in list format. I used the .split() method to convert the whitespace-separated string into a list.

python 
# Convert the string of IPs into a list
ip_addresses = ip_addresses.split()

# Example result:
# ["192.168.1.1", "10.0.0.5", "172.16.0.3", ...]
// HOW .split() WORKS By default, .split() splits on any whitespace (spaces, newlines, tabs) and removes empty strings. Each IP address in the file becomes its own list element, enabling direct item-by-item operations.
// STEP 04

Iterate Through the Remove List

A key part of the algorithm involves iterating through the IP addresses in the remove list. I used a for loop to process each address one by one.

python 
# Iterate through each IP in the remove list
for element in remove_list:
    # Process each element ...
    pass

The for loop assigns each value from remove_list to the loop variable element in turn, allowing the removal logic to run against every address that should be revoked.

// STEP 05

Remove IP Addresses on the Remove List

Inside the loop, I added a conditional check before calling .remove() — this prevents an error if an address from the remove list isn't present in the allow list.

python 
for element in remove_list:
    # Only remove if the IP exists in the allow list
    if element in ip_addresses:
        ip_addresses.remove(element)
// WHY THE if CHECK? Calling .remove() on a value that doesn't exist in the list raises a ValueError. The if element in ip_addresses guard makes the algorithm resilient to mismatches between the two lists — a critical defensive pattern in production scripts.
// STEP 06

Update the File with the Revised List

As the final step, I converted the updated list back into a string using .join(), then opened the file in write mode to overwrite it with the revised allow list.

python 
# Convert the updated list back to a newline-separated string
ip_addresses = "\n".join(ip_addresses)

# Overwrite the file with the revised allow list
with open(import_file, "w") as file:
    file.write(ip_addresses)

The "w" mode opens the file for writing and replaces all existing content. Using "\n".join() ensures each IP address is placed on its own line, matching the original file format.

// SUMMARY

Algorithm Summary

The complete algorithm opens allow_list.txt, reads and parses it into a list of IP addresses, removes any address also found in remove_list, and writes the updated list back to the file — revoking access for any unauthorized IP.

python — full algorithm 
# Full algorithm: update_allow_list.py

import_file = "allow_list.txt"

# Step 1 & 2: Open and read the file
with open(import_file, "r") as file:
    ip_addresses = file.read()

# Step 3: Convert string to list
ip_addresses = ip_addresses.split()

# Steps 4 & 5: Iterate and remove revoked IPs
for element in remove_list:
    if element in ip_addresses:
        ip_addresses.remove(element)

# Step 6: Convert back to string and overwrite the file
ip_addresses = "\n".join(ip_addresses)

with open(import_file, "w") as file:
    file.write(ip_addresses)

// KEY METHODS USED

  • open(file, "r") Opens the file in read mode inside a safe with block
  • .read() Reads entire file contents into a single string
  • .split() Converts whitespace-separated string into a list of IPs
  • for … in Iterates through every address in the remove list
  • .remove() Deletes a matching element from the list (guarded by if in)
  • "\n".join() Converts the list back to a newline-separated string
  • open(file, "w") Opens the file in write mode and overwrites it with the updated list
// OUTCOME The algorithm successfully automates IP access revocation — any address on the remove list is purged from allow_list.txt, ensuring restricted content is no longer accessible to unauthorized parties.
